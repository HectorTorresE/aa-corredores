Visibilidad en Google

También preparamos el sitio para buscadores

So Google can understand and find each page more easily.

  • Títulos y descripciones en español e inglés
  • Vista atractiva al compartir en WhatsApp / redes
  • Archivos para Google (robots.txt + sitemap.xml): permiso para indexar + mapa de URLs
  • Datos de negocio estructurados (tipo de empresa)
Esto no garantiza el puesto #1 en Google; es la base técnica correcta. Con dominio propio se puede conectar Search Console.

Costos · Formulario

¿El formulario suma costo extra?

Short answer: no with what we use today.

Hoy (recomendado)

FormSubmit — gratis. El visitante envía el formulario y el mensaje llega a su correo. No hay servidor que pagar ni infraestructura adicional.

Solo: confirmar el correo la primera vez. Sin panel de control; es “formulario → inbox”.

Si quieren más adelante

Servicios con panel, más antispam o más volumen (Formspree, Web3Forms, etc.) — suelen tener plan gratis limitado y luego ~US$8–15/mes.

Opcional. Solo si el volumen o la fiabilidad lo piden.

Pregunta para ustedes: ¿les basta el formulario gratis a su correo, o prefieren un servicio de pago con panel?
Sin costo de infraestructura hoy

Costos · Hosting

Opciones de hosting (después de aprobar)

Digannos su preferencia — o si ya tienen proveedor / dominio.

A · Gratis + dominio propio

GitHub Pages, Cloudflare Pages o Vercel: hosting $0.

Dominio (~US$10–15/año por marca) es el gasto típico.

B · Hosting tradicional

Si ya tienen cPanel / proveedor en RD u otro país, podemos publicar ahí.

Costo = lo que ya paguen con ese proveedor.

C · Que nosotros gestionemos

Elegimos y configuramos A (recomendado) y les entregamos los dominios apuntando bien.

Hosting sigue pudiendo ser $0; dominio aparte.

Hoy (preview)

GitHub Pages gratis — solo para revisión. No es el dominio final.

Pregunta para ustedes: ¿prefieren A, B o C? ¿Ya tienen dominio o hosting?
